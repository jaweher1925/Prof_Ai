================================================================================
                                KEY CHANGES
================================================================================

REMOVED (❌ Old Approach)
================================================================================
  ✗ Fixed 4-segment structure per slide
  ✗ Complex timeline system
  ✗ Word-by-word animation sync
  ✗ Forced layout positions
  ✗ Per-layout positioning rules
  ✗ Segment nesting complexity
  ✗ 4-sprint implementation timeline

ADDED (✅ New Approach)
================================================================================
  ✓ Scene-based: 1 scene = 1 slide
  ✓ Direct canvas editing: Drag avatar/images
  ✓ Simple text format: User decides structure
  ✓ Dynamic slide count: Matches PDF (not fixed 4)
  ✓ Responsive positioning: Smart layout algorithm
  ✓ 2-week implementation timeline
  ✓ Avatar placeholder: Fully draggable & resizable

================================================================================
                              CORE FEATURES
================================================================================

1. TEMPLATE SELECTION
   • Browse 10 professional templates
   • One-click apply to all slides
   • Template styling applied instantly

2. AVATAR PLACEHOLDER
   • Semi-transparent box on canvas
   • Draggable: Move anywhere on slide
   • Resizable: Corner handles, maintains 16:9 ratio
   • Size: 15% - 50% of slide width
   • Default position: Right side (70%, 50%)

3. TEXT EDITING
   • Click title → Edit text (no forced format)
   • Click bullet → Add/edit/delete points
   • Main points (•) and sub-keypoints (-)
   • User chooses structure (no constraints)

4. IMAGE HANDLING
   • Auto-detected from PDF content
   • User can resize: Click + drag handles
   • Responsive: Won't overlap with avatar
   • User can move/hide/delete

5. SMART LAYOUT
   • 16px snap-to-grid
   • Content won't overlap avatar placeholder
   • Guide lines show safe zones
   • Auto-positions elements intelligently

6. AUTO-SAVE
   • Saves every 500ms (debounced)
   • Visual feedback: "Saving..." → "Saved"
   • No data loss on refresh

DATABASE CHANGE
================================================================================
New table: slide_compositions
Fields:
  • id (UUID)
  • sceneId (links to scene)
  • templateId (which template)
  • title (slide title)
  • contentBullets (JSON array)
  • imageUrl (auto-detected from PDF)
  • avatarX, avatarY, avatarWidth (% of slide, NEW)
  • status, timestamps

API ENDPOINTS (Simple)
================================================================================
GET    /api/scenes/{sceneId}/composition
       → Returns all composition data

PATCH  /api/scenes/{sceneId}/composition
       → Save any/all fields

POST   /api/modules/{moduleId}/apply-template
       → Apply template to all scenes

    └── Avatar placeholder (draggable + resizable)

================================================================================
                        SCENE vs SEGMENT (CRITICAL)
================================================================================

OLD STRUCTURE (❌ Remove)
  Module
    └─ Script
        └─ Scene
            ├─ Segment 1
            ├─ Segment 2
            ├─ Segment 3
            └─ Segment 4 (FIXED 4 SEGMENTS)

NEW STRUCTURE (✅ Keep)
  Module
    └─ Script
        ├─ Scene 1 → Slide 1
        ├─ Scene 2 → Slide 2
        ├─ Scene 3 → Slide 3
        └─ Scene N → Slide N (DYNAMIC COUNT)

Result: Simpler, flatter, matches PDF naturally

================================================================================
                        TEXT FORMAT (FLEXIBLE)
================================================================================

OLD (❌ Forced)
  Every slide MUST have:
  - Exact title format
  - Exact subtitle
  - Exactly 3-5 bullets
  - Specific icon placement

NEW (✅ Natural)
  User can have:
  - Just title? OK
  - Title + bullets? OK
  - Title + description? OK
  - Mixed format? OK
  - Empty? OK (no constraints)

Examples:

     • Definition
     - Technical
     • Business impact

  2. Title: "Key Points"
     • Point 1
     • Point 2
     • Point 3

  3. Title: "Summary"
     Just text here.
